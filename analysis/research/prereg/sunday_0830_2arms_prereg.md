# 臂 1：C9s1 —— 推荐配方的 seed 复现（Task #27）

**主判决轴**：VOC penult mIoU，记 **X**。参照 C9 s0 = 51.59。
**这一臂同时是 §5.22.7 那条事前登记的猜想的检验**：
「两族损失同时在场时，长文本与局部**应该同时稳**」
（G@W0.2 只有 PCM 一族的损失 → 长文本稳 0.5~0.7× 而局部崩 121~222×；
C5 只有区域一族 → 局部稳 0.27~1.93× 而长文本不稳 0.64~2.01×）。

| 出口 | 判据 | 含义 |
|---|---|---|
| **W1 复现，推荐成立** | X ≥ 45.5（即 \|X − 51.59\| ≤ 2φ_MIL 的两倍 = 6.06） **且** 无 `last < penult` 反序 **且** DOCCI 两轴均 ≥ 66.18/66.56（C9 −2φ_G） | **选型表可以合并并对外推荐**。φ 落地后 C9 全部结论改用它。§5.22.7 猜想**命中** |
| **W2 局部不稳但没崩** | 32.0 ≤ X < 45.5 | 散布 ≥2×2φ_MIL → **C9 的局部幅度必须报两 seed 均值，"全项目最高"撤回**；三损失配方的局部一侧确认为高方差 |
| **W3 落进坏盆地** | X < 32.0（或出现 `last < penult` 反序） | **MIL 没有拆掉三损失配方的双峰** → §5.22.7 猜想**被否**，选型表退回分裂状态，V1 降级为"seed 0 上的一次巧合" |
| **W4 长文本崩而局部稳** | DOCCI i2t < 66.18 **或** t2i < 66.56，且 X ≥ 45.5 | 反方向出口：**双峰搬到了长文本一侧**。这会推翻「PCM 给的长文本能力是稳的」（§5.18 全表唯一守住地板的那一族） |

**副判据**（不单独否决，只改陈述）：
1. **四根局部轴的符号一致性**（相对 C9 s0）：4/4 同向 = 干净复现。
2. **`last < penult` 反序**：出现即归入 `gt_base` / G@W0.5 / G@W0.2s1 那族失效形态。
3. **ep5 是否已分开**（G s1 在 ep5 就分开了：VOC last 9.81 vs 39.06）→ 区分"后期崩"与"从头就在另一个盆地"。
4. **五项损失末值**与 s0 差应 <1%（§5.18 同一套核对）；差 >1% 先查平凡解释。
5. **全局五口径散布**：G 族在这里是 0.09~0.32×（很稳），若 C9 两 seed 也 <1× 则
   「全局判别一族对 seed 不敏感」拿到第二个配方族的支撑。

**押注（写下但不参与判决）**：**W1**。三条理由：
(a) C9 s0 的 `last > penult` 在 ep5 与 ep10 都成立（43.50>41.57 / 54.04>51.59），
    而坏盆地的签名是 ep5 就反序；
(b) C9 s0 局部四轴相对 G s0 是 8/8 同向为正、且**超过 G 双峰的两端**
    （> max(39.10, 18.33)）→ 不像是撞上了 G 的好盆地，像是 MIL 抬高了整个分布；
(c) MIL 在纯区域族两 seed 上极稳（φ_MIL 1.51 < 区域族 3.88）。
⚠️ 反方向的顾虑写清：G@W0.2 的两个终点相差 20.77 点而五项损失差 <1% ——
**训练侧看不出来**，所以 (a)(c) 都不是强证据。

# 臂 2：C11 —— 三损失配方 × MIL，把 `W` 推到全局最优点（Task #28）

**唯一变量**：`region_weight` 0.2 → 2.0（相对 C9，同一张 TSV、同 seed、同 `pcm_weight`）。
**为什么现在才能问**：`grid1+mean` 下这个方向已被 G@W0.5 打死（局部崩 148~193×，§5.16），
当时的结论是「G 不许动 W」。而 MIL 已把局部 W 曲线在 [0.5,2.0] 抹平（§5.23，斜率抹掉 42 倍）
→ **那条禁令的前提可能已经不成立。**

**主判决**：联合判据（图像塔要涨、局部与长文本都不许塌）。
记 **Y** = IN-1k top1、**Z** = VOC penult mIoU。

| 出口 | 判据 | 含义 |
|---|---|---|
| **Y1 三损失配方的 W 也能推到 2.0** | Y ≥ 29.0 **且** Z ≥ 45.5 **且** DOCCI i2t ≥ 66.18 **且** t2i ≥ 66.56 | **交付级升级**：一个配方同时拿到 ~30 的 IN-1k、MIL 级局部、G 级长文本 → 选型表**只剩一行**，"图像塔要区域单跑 W2.0"这条也被合并 |
| **Y2 图像塔涨了但长文本被吃掉** | Y ≥ 29.0 **且**（DOCCI i2t < 66.18 **或** t2i < 66.56） | **PCM 与区域分支在权重上是零和的** → 长文本与图像塔的 trade-off 回到 `region_weight` 这一根旋钮上，选型表保持两行但**边界从"配方"变成"W"**（比现在干净） |
| **Y3 局部塌了** | Z < 45.5 | **MIL 没有解除 W 上限，禁令只是被推迟** → §5.23「MIL 抹平下降段」在三损失配方里不成立（跨族不迁移，是个独立收获） |
| **Y4 图像塔没涨** | Y < 29.0 且 Z ≥ 45.5 | 反方向出口：**C9 的图像塔差不是 W 造成的** → 归给 PCM 分支本身或数据量，`W` 在三损失配方上是死区（与 §5.11 的梯度占比结论冲突，需复查） |

阈值来处（全部事前算好，不许事后调）：
- **Y ≥ 29.0**：C9 = 25.98，按 `grid1+mean` 的 W0.2→2.0 增幅 +6.50 打 46% 折 = +3.0。
  取一个**保守但不空洞**的门槛：只要拿到增幅的 46% 就算"涨了"。（2φ_G = 1.33 → 3.0 = 2.3×）
- **Z ≥ 45.5**：与 W1 同一条线（C9 51.59 − 2×2φ_MIL）。
- 长文本两条 = C9 − 2φ_G（69.12−1.47 / 68.94−1.19 后取整到 66.18 / 66.56，
  与 W1 同一条线，两臂共用便于交叉读）。

**副判据**：
1. **k-NN bb**：C9 44.58 → 若 ≥ 48.0（拿到 `grid1+mean` 那 +5.93 的 58%）则图像塔一侧独立复核通过。
2. **ADE penult aAcc**（MIL 族最灵敏轴，2φ=0.28）：C9 19.08。纯 MIL 族上这个量随 W 单调降
   （W0.5 20.69 → W2.0 15.66 → W4.0 11.54）→ **事前预测 C11 应落在 15~16**；
   若它反而不降，说明 PCM 分支在细类上有独立保护作用（新机制线索）。
3. **`Region_loss` 只用于核对强度对齐**（§5.21.3），不参与选配方。
4. **ep5 四读出**：分开"终点抽样"与"结构性差异"。

**押注（写下但不参与判决）**：**Y2**。理由：区域损失权重从 W=0.2 抬到 2.0 会把区域分支的
损失占比从 ~18% 推到 ~68%（§5.11 的梯度占比近似正比于 W），PCM 分支被挤是最自然的后果；
而局部一侧我押不塌（§5.23 的抹平 + §5.25 的膝点右移都指向 W=2.0 仍在平台上）。
