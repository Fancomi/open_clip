## 1. 这一臂在问什么

C11（丢行表，`pcm-region grid2+mil` **W2.0** p0.2 s0）判过 **Y3（局部塌了）**，
并由此得出「三损失族的 `W` 轴关闭在 0.2」。但 §5.29/§5.30/§5.31 之后我们知道：
**丢行表污染的不只是指标值，还污染了噪声地板本身**，而且它在三损失族上造出过
一个 29.23 点的假双峰（`_full` 表上 3/3 都落好盆地，φ 从 41.33 掉到 3.12）。

⇒ **C11 的 Y3 判决是在被污染的表上做的。** 本臂 = C11 唯一换表（丢行 → `_full`），
问：**三损失配方在生产表上还是不许动 `W` 吗？**

同时它是 §5.32.2 那条新结论的**样本外检验**。§5.32.2 说
「三损失族相对 C5 的 −5.87 图像塔差 = 纯区域族 W0.2→W2.0 的差」，
这句话有一个直接的、可伪证的推论：**如果差的真是 `W`，那把三损失配方的 `W` 抬到 2.0
就应该把这 5~6 点收回来。** C11（丢行）给的是 −0.28（几乎零回收），
纯区域给的是 +5.93~+6.50。**两个预测差约 6 点 ≈ 43× 地板** —— 这是本项目
现存开放问题里判决带宽最宽的一个。

## 4. 主轴与出口（起训前定死）

**主轴 M = k-NN backbone**（纯图像口径，回收率问题的正靶）。
参照点：C9F 族 n=3 均值 **46.62**；C5 两 seed 均值 **52.49**。
回收率定义 `R = (M − 46.62) / (52.49 − 46.62) = (M − 46.62) / 5.87`。

| 出口 | 条件 | 读作 |
|---|---|---|
| **AB1** | M ≥ 51.0（R ≥ 75%） | **§5.32.2 成立且强** —— 差的就是 `W`，生产表上抬 W 能把图像塔收回来 |
| **AB2** | 48.5 ≤ M < 51.0（32% ≤ R < 75%） | 部分回收，`W` 是主因但有第二项 → 报 R 到一位有效数字 |
| **AB3** | 46.9 ≤ M < 48.5（5% ≤ R < 32%） | **§5.32.2 的推论被削** —— 跨族 `W` 差值解释不了这个洞，需新候选 |
| **AB4** | M < 46.9（R < 5%，含反向） | **C11 的 −0.28 在生产表上复现** → 「三损失配方里 `W` 对图像塔没有通路」升级为两表结论 |

**协轴 L = VOC penult mIoU**（判「抬 W 局部塌不塌」，即 Y3 在生产表上是否复现）。
参照点：C9F 族 n=3 均值 **52.27**；C11（丢行）26.70；C5 两 seed 均值 46.70。

| 出口 | 条件 | 读作 |
|---|---|---|
| **AC1** | L ≥ 46.0（距 C9F 均值 −6.27 以内，≤ 2.0φ） | **Y3 不复现** → 「三损失族 W 关闭在 0.2」是丢行表的产物，`W` 轴要重开 |
| **AC2** | 33.0 ≤ L < 46.0 | 塌了但没塌到 C11 那么狠 → 中间态，报 (52.27−L)/3.12 |
| **AC3** | L < 33.0 | **Y3 复现** → 「三损失配方不许抬 W」是配方的性质，不是表的性质 |

⚠️ **四种组合都要能读，不留「未决」**：
- AB1/AB2 + AC3 = **零和确认**（图像塔与局部在 `W` 上真是零和）→ 选型表保持分裂，
  但「用 W 换图像塔」第一次成为可用的显式取舍；
- AB1/AB2 + AC1 = **两边都赚** → C11F 直接成为新的生产配方候选，须立刻排 seed 1；
- AB3/AB4 + AC3 = **纯亏** → `W` 轴对三损失族彻底关闭（两表证据），
  且 §5.32.2 的洞重新变成无来源 → 下一个候选写死为「PCM 分支 × 高 W 的交互项」；
- AB3/AB4 + AC1 = **`W` 在这一族两侧都失效**（既不抬图像塔也不塌局部）
  → 直读「三损失配方下 `region_weight` 是死旋钮」，比任何一边的结论都强。

## 5. 副判据（各自独立，不参与主判）

1. **长文本**：DOCCI i2t/t2i 相对 C9F 族均值（72.83 / 75.57）。
   §5.28.2 在丢行表上判过「区域两项占损失 62.8%→91.9%、`Pcm_loss` +12.5%，
   而下游长文本一点没动（0.55×/0.14×）」→ **本臂检验它在生产表上是否复现**。
   过 2φ（5.20 / 3.08）才算动了。
2. **ADE penult aAcc**：§5.31.4 已定这一族此轴 φ = 5.28（左偏长尾）
   → 只有 |Δ| ≥ 10.6 才写结论；**⛔ 不许把纯 MIL 族那个 0.28 的高灵敏度外推过来**
   （§5.31.6 已明令）。
3. **`penult` 与 `last` 是否分道**：§5.28.5 在 C11（丢行）上第一次看到
   「每根 penult 轴 ep5→ep10 都降、每根 last 轴都升」，并据此把 `penult` 定为
   越界早期探针。本臂**只记录该签名是否复现**，不参与判决。
4. **损失占比**：读 ep9 的 epoch 均值（§5.27 铁律：不许用最后一个 batch）。
   预期区域两项占比从 ~63% 抬到 ~92%（C11 实测值）→ 若差异 >5 个百分点，
   说明换表也改了损失结构，需在写结论时标注。
