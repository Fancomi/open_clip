# 预登记：C6 = `grid=2 + agg=mean` no-op 对照臂（Task #19）

写于 2026-08-28，**起训之前**。C5 判决（§5.20，M1 大胜 + 逐类 P-B）已落盘并 push

## 它回答的唯一问题

**C5 的 +23.00（VOC penult 24.23 → 47.23）是 MIL（`max` 聚合）给的，还是仅仅
"2×2 比 1×1 采样更密"给的？**

C5 一次改了两件事：`roi_align` 输出从 1×1 变 2×2、聚合从 mean 变 max。
逐类判据判 **P-B 均匀上抬**（细长组 Δ +22.78 − 色块组 +22.22 = +0.56 < 3.0）
→ 预设机制"1×1 均值稀释细长目标"**没被确认** → P-B 原文规定
「必须补 no-op 对照臂才能写结论」。本臂就是那个 no-op 臂：
**只改 `--region-roi-grid 1 → 2`，`--region-roi-agg` 保持 `mean`。**

强度混淆项已在 C5 上实测排除（两臂加权 `Region_loss` 比值 1.030 → 1.019）；
`grid=2+mean` 与 `grid=1+mean` 在数学上是**同一个平均池化的更细划分再等权平均**，
名义强度天然更接近 → 本臂的强度混淆比 C5 还小。

## 主判决轴与地板

主判决轴 = **VOC penult mIoU**（与 C5 同一根，理由见 `/tmp/c5_prereg.md`：
四根 OVSS 轴里唯一在悲观地板下仍有功效的一根）。
记 **A = C6 的 VOC penult mIoU**。两个参照点：

- CTRL `grid=1+mean` W2.0 seed0 ep10 = **24.23**
- C5 `grid=2+mil` W2.0 seed0 ep10 = **47.23**

判决带宽 = 23.00。地板一律借**纯区域臂实标 φ**（§5.19）：
**VOC penult φ = 3.88（严格无偏读法）/ 2.74（字面读法）**，取 **2φ = 7.76**（无偏）
作为判决门槛，字面读法的 5.48 只用来做"结论是否随读法翻转"的检查。
→ 带宽 23.00 = **5.9φ**，三分带各留 7.76 后仍剩 7.5 的中间带 → **功效足够**（§6.3 第五条要求）。

⚠️ `grid=2+mean` 又是一个新族，它自己的 OVSS φ 同样未标 —— 与 C5 同一个限制，
所有 ÷φ 都是借来的，**只能定量级**。

## 四个出口（三分带 + 符号，含反方向出口）

| 出口 | 判据 | 含义 / 下一步 |
|---|---|---|
| **N1 MIL 是主因** | A ≤ **32.0**（= 24.23 + 2φ）且 47.23 − A ≥ 2φ | 更密采样本身几乎不值钱，`max` 聚合是全部功劳 → 沿 MIL 轴推进：S=3 + `mil`、C5 铺到其它 W |
| **N2 密采样是主因** | A ≥ **39.5**（= 47.23 − 2φ）且 A − 24.23 ≥ 2φ | MIL 贡献落在噪声内 → **改用更简单的 `grid+mean`**，下一步 S=3 + `mean`；并回头质疑"框内一个格子命中"这个动机 |
| **N3 各占一半** | 32.0 < A < 39.5 且两侧差都 ≥ 2φ | 两个因素可加 → 报拆分比例，下一步 S=3 + `mil`（两个方向同时加密） |
| **N4 反方向：mean 更好** | A ≥ **55.0**（= 47.23 + 2φ） | **MIL 是净负** → 直接弃用 `mil`，并把 §5.20 的机制叙述整体改写 |

⚠️ 若 A 落在 32.0~39.5 但**某一侧差 < 2φ**（即"既没显著低于 C5 也没显著高于 CTRL"这类
半重叠情形）→ 判 **N3′ 不可分辨**，结论写"归因仍未定，需要 n≥2 或换更大 query 数的局部集"，
**不许挑一个方向讲**。

## 副判据（只记录，不参与主判决）

1. **长文本代价是 MIL 专属还是密采样带来的**（§5.20 唯一确认的代价：DOCCI t2i
   22.10 → 18.60 = −3.50 = 2.43× 地板 1.44）：
   - C6 的 DOCCI t2i **≥ 19.22**（= 22.10 − 2×1.44）→ **代价是 MIL 专属**，
     则"要长文本就别用 `mil`"成为可执行的选型规则；
   - C6 的 DOCCI t2i **≤ 19.22** → 代价来自密采样本身，与聚合方式无关。
   Urban 两项地板粗（2.36），**1×~2× 一律写未决**，不给否决权（§6.3 第四条）。
2. **全局五口径**：C5 是四负一正、全部 0.3~1.5× 地板（噪声内）。
   若 C6 也是同一形状 → 那个 ≤0.5 点的疑似全局代价与聚合方式无关，是密采样的。
3. **逐类**：再记一次细长组/色块组（C5 判 P-B 均匀上抬）。
   ⚠️ **标尺钉死为加性差，门槛 ±3.0** —— C5 这次的教训是"按比值看细长组更受益"
   不能事后拿来救机制，本臂同样不许换标尺。
4. **`Region_loss` 逐 epoch 轨迹**三臂并排（CTRL 14.77→8.78 / C5 15.22→8.95 / C6 ?）
   → 若 C6 与 CTRL 几乎重合（预期，等权细分平均），则强度这一项彻底出局。
5. **ADE penult / VOC last / ADE last 三根轴只记录不判决**（同 C5）。

## 押注（写下来，但不影响判据）

押 **N3 偏 N2** —— 猜密采样占大头。理由：C5 的逐类是均匀上抬（P-B），
