## 3. 判据

### 3.1 P3（主分支 `caption_short` + 无 PCM） vs **P0** —— 主轴 k-NN backbone，门槛 0.28

Δ ≡ P3 − 38.89。**这一轴的先验已在 §5.40.1 事前写死，本节照抄不改。**

| 出口 | 条件 | 判读 |
|---|---|---|
| **V1** | P3 ≥ **45.8**（≈ C1 的 46.81 − 1） | **P0 那 −7.73 全部归给「主分支被长 caption 单极化」** ⇒ 短 caption 对图像塔**没有**独立价值；连带确认「文本塔见不到短文本会连图像塔一起拖下水」这条机制，是本项目第一次把文本侧分布单极化的代价量化 |
| **V2** | 41.0 ≤ P3 < 45.8 | **两个候选各占一部分** ⇒ 按 (P3−38.89)/(46.81−38.89) 报回收率，**只报点估计不报显著性**（分母跨两族） |
| **V3** | \|P3 − 38.89\| < 0.28 | **换主分支 caption 没用** ⇒ 那 −7.73 归给「短 caption 对图像塔的独立价值」，即**短文本本身是图像塔的必要监督**，与单极化无关 |
| **V4** | P3 ≤ **38.61** | **反方向：换成短 caption 更差** ⇒ 升格为独立发现（长 caption 对图像塔另有独立贡献），**不许折叠进 V3** |

**协轴 1 = 短提示族（IN-1k zs / COCO i2t / COCO t2i），门槛 0.40 / 0.72 / 0.24。**
§5.40.1 的机制预测**在这里被直接检验**：若「短提示崩塌 = 文本塔没见过短文本」成立，
则 P3 的这三个口径应从 P0 的 5.52 / 10.78 / 3.87 **大幅回升**（C1 是 27.50 / 26.30 / 18.94）。
三分带写全：≥ +门槛 ⇒ 机制确认；|Δ| < 门槛 ⇒ **机制被否**（短提示崩塌与主分支 caption 无关，
须另找原因）；≤ −门槛 ⇒ 反方向升格为独立发现。
📌 **这是本批唯一一根「事前有明确点预测方向」的轴**，也是 §5.40.1 那张事后分组表的确认臂。

这条结论要重写 —— 这是本批唯一能反过来打掉上一批主结论的格子，**必须报**。

## 5. 口径限制（判决时照抄进结论）

1. **三臂全部 n=1。** P3 的对照 P0 也是 n=1 ⇒ §3.1 一切结论写「seed 0 上」。
2. **P3−C1 差 `region_shared_scale` 一项** ⇒ 只作参照点，**不作判决**（§0.1）。
3. **C15′ 的 thr=0.0 同时改「丢框 39.92%」与「错配 53.95%」两件事，本臂拆不开** ——
   拆分完全依赖 §3.3 的 C16−C15′，而那一格有跨盆地风险（§3.3 末）。
4. **C14′/C15′ 都是「增强 + 框集合」同时动的净效应臂**：`thr` 扫描只能拆出「丢框那一部分」，
   **拆不出「增强本身」**（要拆需一个「裁剪但不删任何框」的臂，本批不排）。
5. **`scale=(0.9,1.0)` 从 08-24 起从未扫过**，crop-aug 整条线都坐在这一个点上。
6. **未跑逐类 IoU**（全项目欠账，本批也不补）。
7. **Urban 无否决权**（φ 3.42/2.31，且 n=1000 的 query 抽样噪声本身 ≈2.5 点）。
8. **丢框率与错配率用的是 CPU 代表性切片**（`clip_train_region.tsv` 1/100 = 2 万图，
   `mon_0907_3arms_prereg.md` §0）：thr=0.0 丢框 39.92% / 错配 53.95%；
   thr=0.6 → 0.23% / 0.27%；thr=0.8 → 1.37% / 2.41%。
   **旧的 26.2% / 6.9% / 1.8% 来自不具代表性的 k24 表前 3000 行，不再引用。**
9. **步数混淆**：本批三臂都是固定 10 epoch，与各自对照同 epoch ⇒ 本批不涉及。
