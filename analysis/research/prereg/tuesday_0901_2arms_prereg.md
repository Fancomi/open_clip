## 背景（本批次为什么排这两臂）

§5.30 把三损失族的「局部双峰」归因给**丢行表**：同一配方换成 `clip_train_pcmregion_full.tsv`
后，两个 seed 的 VOC penult 散布从 **29.23 → 2.21**（缩 13.2 倍），且 V1「三族兼得」四条判据
在两臂上全过。但我在写 §5.30 时自己补了一条功效限制：**若真实分布仍是 50/50 双峰，
「连抽两个 seed 都在好盆地」的概率是 25%**，2×2 表的 Fisher 精确检验 p = 0.5 → 当时写的是
「连抽两个 seed 都在好盆地」，**不是**「双峰已被证明消除」。第三个 seed 是唯一能把这句话
升级成结论的臂 → 臂 1。

臂 2 来自一个建表事实：`clip_train_region.tsv` 的 `--max-region 12` 是**建表期硬截**，
全表 stride 抽样（n=191,266，覆盖整表）显示 **79.67% 的图正好卡在 12**、**0% 超过 12**
→ 训练侧单调 `MAX_REGION=24` 是**静默 no-op**（这一点在花 GPU 之前查出来了）。已用
`--max-region 24` 重建：

| 表 | 行数 | 区域/图 | 卡在上限占比 | 区域数 >12 占比 |
|---|---|---|---|---|
| `clip_train_region.tsv` | 2,868,984 | 10.92 | **79.67%**（=12） | 0.00% |
| `clip_train_region_k24.tsv` | 2,868,984 | **18.71** | **52.12%**（=24） | **77.41%** |

新增的框系统性更小（前 2 万图，归一化面积）：中位数 0.1205 → **0.0674**，
面积 <1% 的框占比 6.37% → **17.37%**。这与 §5.20 的机制读法直接对上——建表期按**面积降序**
截断，被砍掉的正好是**最小的框**，而 MIL 的抗稀释增益就来自细长/小结构。

⚠️ **本臂结构上无法拆开的混淆项（写在跑之前）**：K 从 12 抬到 24 同时改了两件事——
(a) 每图监督目标数近乎翻倍（更多信号）、(b) 新增的具体是**小框**（不同分布的信号）。
在 k24 表上回设 `MAX_REGION=12` 也拆不开，因为那会按面积降序取回原来那 12 个框（等价于 k12 表）。
要拆只能造一张「随机抽 12 个框」的第三张表 → 本批次不做，本臂只判「K 是不是旋钮」。

⚠️ 另一条限定：区域坐标假定 resize-only 变换（无 RandomResizedCrop），这在 k24 上与 k12 完全一致，
不引入新风险。

## 臂 1：C9Fs2（Task #32）—— 三损失族第三个 seed

配方：`pcm-region`，`clip_train_pcmregion_full.tsv`（286.9 万），`REGION_ROI_GRID=2`
`REGION_ROI_AGG=mil` `REGION_WEIGHT=0.2` `MAX_REGION=12` `PCM_WEIGHT=0.2` `PCM_DIM=32`
`EPOCHS=10` **`SEED=2`** `DV_SUFFIX=-Fs2` `PORT=29738`。
预计 8h30m 训练 + 35m 评测（按 C9Fs1 实测有效吞吐 936 samples/s 外推）。

**主轴 X = VOC OVSS penult mIoU**。参照：C9F(s0) **52.74**、C9Fs1 **50.53**、两 seed 均值 **51.64**；
本族 `_full` 表实标地板 2φ(VOC penult) = **3.13**；纯 MIL 族 2φ_MIL = 3.03（两者 1.03× 一致，
§5.30.3 是全项目最好的一次借用符合度）。

四个出口（三分带 + 符号，含反方向出口）：

- **AA1 — X ≥ 44.0 且形态正常**（`last > penult` 在 ep5/ep10 都成立、VOC last 在 50 分段）
  → 3/3 落在好盆地。**可以写「丢行表是双峰的原因」这个结论**，但必须同时诚实报
  Fisher 精确 p = **0.25**（3/3 vs 1/2 的最好情况），即「若仍是 50/50 双峰则本观察概率 12.5%」。
  V1「三族兼得」升到 n=3；本族地板从三臂重标（σ̂ 自由度 2，CI 仍宽但比 n=2 强）。
- **AA2 — X < 32.0 或任一 (epoch × 读出) 出现 `last < penult` 反序**
  → 坏盆地复现在生产表上 → **V1 第二次死**，「双峰是丢行表的产物」作废，改判
  「双峰是**配方**的性质，与唯一数据量无关」；选型表长文本那一行永久标注「seed 不稳，
  用前必须自查 VOC penult」。§5.30 主结论整段撤回。
- **AA3 — 32.0 ≤ X < 44.0 且形态正常**
  → 出现**第三个终点** → 不是双峰而是**宽分布**；本族局部地板要重标到大一个量级
  （单这一条就会让 §5.30.4 那句「与 C5 局部不可区分」和 §5.30.2 的 V1 全部重判）。
- **AA4 — X > 55.9**（= 52.74 + 3.13，显著高于目前最好的那个 seed）
  → 均值上移 → 局部代表值改用三臂均值，§5.30.4 的 `+4.94 = 1.63×` 需重算，
  有可能跨过 2× → 那时「C9F 族局部显著优于 C5」才第一次可写。

门槛来处（写清算术，防事后调参）：
- **44.0** = 51.64 − 2.4 × 3.13（两 seed 均值下移 2.4 个地板；比 2× 略松是因为 n=3 时
  单臂偏离均值的期望本就比 seed 对大）。
- **32.0** 与上一批 Z4 用同一条线，跨批次可读。
- **55.9** = 52.74 + 3.13。

副判据（各自独立记录，**不参与主判**）：
1. **ADE penult aAcc 落在 [9.2, 26.1]**（= 两臂 min/max ± 本族实标 φ 6.25）。
   §5.30.5 已把这一轴定性为「与盆地切换无关的独立轴」（丢行表跨 29.23 点盆地时它只动 0.03，
   而 `_full` 表同盆地内它动了 4.42）→ 本臂是这句话第一次样本外检验。
2. **全局五口径（IN-1k / k-NN bb / proj / COCO i2t / t2i）三臂极差 ≤ 2× 本族实标地板**
   （IN-1k 0.27 / bb 0.04 / proj 0.16 / i2t 0.48 / t2i 0.01）。⚠️ 这几个地板是 n=2 实标，
   小到不可信（COCO t2i 的 0.01 尤其），**极差超 2× 只当「地板标小了」记录，不当异常**。
3. **DOCCI i2t 落在 [69.2, 75.9]**（两臂 71.70 / 73.44 ± 2.46）。
4. **五项损失 epoch 均值三臂两两差 <1%**（必须用 `Loss: x (y)` 的括号内 epoch 均值，
   §5.27 铁律；用末 batch 会把差放大 3.8 倍）。⚠️ §5.30.5 已证这条是**必要非充分**——
   §5.27 里训练侧差 <2% 而下游差 29.23 点 → **本条通过不构成 AA1 的证据**。
5. **有效吞吐（累计样本 ÷ 墙钟）落在 900–980 samples/s**（C9F 961–981 / C9Fs1 936）。

**押注：AA1**（弱）。理由只有一条弱的：§5.30.3 里 17 个口径的 seed 对散布**全部**塌到本族
小地板、且局部地板与纯 MIL 族 1.03× 吻合，这个「整体一致」比单看主轴更难由巧合产生。
明确不作为理由的：训练侧五项损失吻合（§5.27 反例）。

## 臂 2：C12（Task 待建）—— C5 配方 × K=24

配方：`region`（纯区域，无 PCM），`REGION_TSV_NAME=`**`clip_train_region_k24.tsv`**
（本批为 `region)` 分支新增的换表入口，与 `pcm-region)` 的 `PR_TSV_NAME` 同形），
`REGION_ROI_GRID=2` `REGION_ROI_AGG=mil` `REGION_WEIGHT=2.0` **`MAX_REGION=24`**
`EPOCHS=10` `SEED=0` `PORT=29740`（输出目录 `regw2.0k24-roi2mil_...`，`k24` 已自带区分度，
不加 `DV_SUFFIX`）。⚠️ **换表必须同时传 `MAX_REGION=24`**：只换表不改这个数，训练侧仍按
默认 12 按面积降序截 → 精确等价于旧表，又是一次静默 no-op。
对照 = **C5**（同配方 K=12，两 seed 均值）。预计 5h31m + 35m（按纯区域 1444 samples/s；
但 K 翻倍会拖慢，见副判据 2）。

**主轴 M = ADE20K-150 penult mIoU**。选它而不选 VOC penult 的理由（§5.16 第五条：
指定仲裁口径前先查它对**本问题**有没有分辨力）：本臂的机制预测是「救回小/细长结构」，
ADE 有 150 个细类、VOC 只有 20 个粗类，而 §5.24 已实测「VOC 20 粗类比 ADE 150 细类
宽容得多」→ 细类轴才有分辨力。参照：C5 两 seed 均值 **5.71**，2φ_MIL(ADE penult mIoU) = **1.64**。
**协轴 N = VOC penult mIoU**（C5 均值 46.70，φ 3.03）。
**护栏：k-NN bb（C5 52.49，φ 0.30）、IN-1k（33.59，φ 0.32）**。

四个出口：

- **K1 — M ≥ 9.0**（= 5.71 + 2.0 × 1.64）→ **K 是真旋钮**，`max_region` 进生产配置，
  下一步扫 K=48 / 完全不截。
- **K2 — |M − 5.71| < 1.64 且 |N − 46.70| < 3.03** → **K 轴关闭在 12**，
  「被砍掉的小框语义不可靠（grounding 噪声集中在小框）」得到支持；
  连带把 `max_region` 从积压里删掉。
- **K3 — M ≤ 4.07 或 N ≤ 43.67**（任一显著变差）→ **小框有害**，
  建表期的面积降序截断是**有益正则**而非缺陷 → 反向排 K=6 验证「更狠地截更好」。
- **K4 — M ≥ 9.0 但 k-NN bb ≤ 50.4 或 IN-1k ≤ 31.5**（局部涨、全局显著掉）
  → K 是一个**新的局部/全局 trade-off 旋钮**（与 `W` 同类），选型表要加一维。

副判据：
1. **逐类 IoU**：`bicycle / chair / sofa / person`（§5.11 的细长类垫底组）的涨幅应大于
   `cat / car / train`（色块类）。**这是本臂唯一有方向性的机制预测** → 若 M 涨而逐类
   涨幅分布相反，「救小框」这个机制读法否掉、改记「只是监督目标变多」。
2. **吞吐预期 −20~35%**（区域分支的 `roi_align` 与文本编码量近乎翻倍）。
   若掉 >50%，先查是不是 OOM 重试（§「静默失败陷阱」：碎片型 OOM 用
   `PYTORCH_CUDA_ALLOC_CONF=expandable_segments` 而不是改 batch）。
3. **OOM 风险**：K=24 让每 batch 的区域数翻倍 → 队列里本臂**头部加一次 ~200 step 冒烟**，
   过了再放全程，避免 5h31m 白跑。

**押注：K1**（弱）。K3 有实打实的概率——建表期按面积降序截断当时是**有意为之**，
理由是小框 grounding 更可能是噪声；这个理由本身没被检验过，本臂正是检验它。
