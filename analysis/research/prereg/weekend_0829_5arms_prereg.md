# 臂 1：C5s1 —— MIL 族 seed 复现 / 实标 φ（Task #20）

**为什么它排第一**：C5 的 `+23.00` 是本项目迄今最大的单步结果，而它是 n=1；
而本项目**已经出现过一次局部指标双峰**（G@W0.2 换 seed 崩 222× 地板，§5.18）。
在 seed 1 落地之前，§5.20 / §5.21 的每一句都得挂着「seed 0 一次抽样」。

**主判决轴**：VOC penult mIoU，记 **B**。参照：C5 s0 = 47.23，CTRL = 24.23，2φ = 7.76。

| 出口 | 判据 | 含义 |
|---|---|---|
| **R1 复现** | B ≥ 39.5（即 B − 24.23 ≥ 15.27 ≈ 3.9φ） | C5 效应确认。φ_MIL := \|47.23 − B\| 落地，后续 MIL 结论全部改用它 |
| **R2 部分复现** | 32.0 ≤ B < 39.5 | 相对 CTRL 仍 ≥2φ，但两 seed 散布 ≥ 7.7 ≥ 2φ → **幅度必须报两 seed 均值，MIL 族 φ 比区域族大 ≥2 倍 → 所有 MIL 结论降级为"方向性"** |
| **R3 不复现** | 16.5 ≤ B < 32.0 | 与 CTRL 不可区分 → **§5.20 / §5.21 主结论全部撤回**（含 C6 归因：C5−C6 的 19.33 失去参照） |
| **R4 反向** | B < 16.5（比 CTRL 低 ≥2φ） | **MIL 是双峰的**，与 G 那族同形态。必查 `last < penult` 反序签名 |

**副判据**（都不能单独否决主判决，只改陈述方式）：
1. **另三轴符号一致性**：VOC last / ADE penult / ADE last 相对 CTRL 是否同为正。
   3/3 同向 = 干净复现；≤1/3 = 即使主轴过关也只能写"单轴复现"。
2. **`last < penult` 反序**：出现即归入 `gt_base` / G@W0.5 / G@W0.2s1 那族失效形态（§5.18 第 4 步）。

4. **ep5 值**：若 ep5 已领先 CTRL ≥10 点，则"不是终点抽样"再加一条独立证据。

**押注（写下但不影响判据）**：**R1**。三条理由：(a) 纯区域族 φ 已实标且小（3.88），
双峰只在**三损失**配方上出现过；(b) C5 在 ep5 就已领先 C6 14.04 点（§5.21.2）；
(c) C5 的 mIoU 与 aAcc 同向（§5.20.1）——双峰失效的签名是"贴错标签"（mIoU 崩而成片不崩），C5 没有。

# 臂 2：C8 —— MIL 下重扫 W（局部最优 W 是否被搬动）

**为什么必要**：§5.20 写下的头号论断是「**局部/全局冲突是特征取法的性质，不是 `W` 的性质**」。
这句话目前只有**一个 W** 的证据（W=2.0）。在 `grid1+mean` 下，
W 0.5→2.0 的局部代价是 **37.32 → 24.23 = −13.09（3.4φ）**。若 MIL 下这个斜率还在，
那句论断必须改写。**这是最可能改结论的一臂。**

**主判决轴**：VOC penult。记 **V**，关键量 **Δ_W = V − 47.23**（MIL 下 W0.5 减 W2.0）。
对照量：`grid1+mean` 下同一比较是 **+13.09**。

| 出口 | 判据 | 含义 |
|---|---|---|
| **S1 冲突已消除** | \|Δ_W\| < 7.76 | MIL 下 W 在局部口径上**变平** → 与全局最优 W=2.0 合起来 = **存在同时最优点（W2.0 + grid2mil）** ← 交付级结论，§5.20 那句论断确认 |
| **S2 冲突仍在、只是整条曲线上移** | Δ_W ≥ +7.76 | 低 W 仍更好 → 论断改写成「MIL 抬高了整条曲线但没抹平斜率」，且**局部推荐配方要改成 W0.5+MIL** |
| **S3 反转** | Δ_W ≤ −7.76 | W=2.0 在 MIL 下反而局部更优 → 冲突彻底反向，第 4 臂（W4.0+MIL）的价值上升 |

**副判据**：
1. **全局五口径 vs `grid1+mean` W0.5**（49.49 / 48.72 / 30.45 / 29.98 / 21.18）——
   检验 §5.21.4 的「密采样带来 ≤0.5 点全局代价、5/5 同号为负」在**低 W** 上是否复现。
   若复现（5 项同号负、每项 <2× 地板）→ 该代价与 W 无关，是密采样的固定开销。
2. **DOCCI t2i vs 19.70** —— 检验 §5.21.5 的新猜想（「代价来自 2×2 让每个格子都要对上整条短语」）。
   若代价随 W 变小按比例缩小（W0.5 的 Δ 明显小于 W2.0 的 −2.92）→ **代价 ∝ 区域分支强度**，
   支持猜想；若 W0.5 的代价一样大 → 代价与强度无关，猜想要另找机制。
3. ADE 两读出 vs 4.05 / 5.60（记录，不判决 —— ADE penult 在低 W 上本来就接近区域族峰值）。

**押注**：**S2**。理由：C6 证明密采样本身几乎不值钱（0.95φ），MIL 更像一个**乘性放大器**
（把"框内最像的格子"挑出来），乘性放大不改变 W 的斜率符号。

# 臂 3：C7 —— `grid=3 + mil`（沿 MIL 轴继续推，Task #22）

**为什么它是"沿 MIL 轴"而不是 §5.20 原写的"S=3 加密"**：C6 判 N1 之后方向改了 ——
加密本身只值 0.95φ，`max` 聚合值 4.98φ。所以第三格要**带着 mil 一起加**。

**事前写下的失效模式**：框短边在 14×14 map 上中位 **4.08** feature px（≥2px 占 84.30%）
→ S=3 时每格 ≈1.36 px，**亚像素**。插值会让相邻格子近乎相同 → `max ≈ mean` → 退化成 C6。
离线扫（固定对齐度）给出 mil/mean 比值 S=1/2/3/4 = 1.00/1.63/1.83/1.93
→ **S=3 相对 S=2 只多 12%**。

**主判决轴**：VOC penult，记 **V**。参照 C5 = 47.23、C6 = 27.90，2φ = 7.76。

| 出口 | 判据 | 含义 |
|---|---|---|
| **T1 继续涨** | V − 47.23 ≥ +7.76 | S 轴未饱和 → 值得补 S=4，且"亚像素"这条离线论证被推翻 |
| **T2 饱和** | \|V − 47.23\| < 7.76 | S=2 已拿到全部收益（与离线的 +12% 一致）→ **grid 轴关闭，不再排 S=4** |
| **T3 过密有害** | V − 47.23 ≤ −7.76 **且** V − 27.90 ≥ +7.76 | 有代价但仍远好于 mean → 最优 S 落在 2 |
| **T4 塌回 mean** | \|V − 27.90\| < 7.76 | 亚像素让 `max ≈ mean` —— **事前写下的优雅失效模式被直接观测到** |

**副判据（这一臂真正想买的第二个信息）**：§5.21.5 的长文本猜想。
猜想原文：「2×2 让框内每个格子都要单独对上整条短语 → 逼短语编码'任意子区域都成立'，
与整图级长程聚合冲突」。若成立，**格子越多越伤**。

| 参照 | DOCCI t2i |
|---|---|
| CTRL `grid1` | 22.10 |
| C6 `grid2+mean` | 19.18 |
| C5 `grid2+mil` | 18.60 |

判据：C7 的 DOCCI t2i **≤ 17.16**（= 18.60 − 1.44）→ ✅ 支持猜想；
**≥ 20.04**（= 18.60 + 1.44）→ ❌ 反向否掉（格数不是原因，得另找）；中间 → 未决。
⚠️ 若 C7 落进 T4（塌回 mean），则本副判据**降级为记录**：格子在数值上已不起作用，
长文本一侧同时看不出变化才是自洽的。

**押注**：**T2**（离线 +12% + 亚像素两条独立论证同向）。长文本副判据押"未决"。

# 臂 4：C10 —— `grid=2 + mil` W=4.0（把 MIL 下的 W 曲线补成三点）

**为什么必要**：臂 2 给 W0.5，本臂给 W4.0 —— 加上 C5 的 W2.0，MIL 下的 W 曲线才有**形状**
而不是两个点连一条直线。`grid1+mean` 下这条曲线是**单调降**（37.32 → 24.23 → 22.51），
且 W=4.0 是「全局进平台 + 局部无平台继续掉 + 长文本 Urban 收回」三件坏事同时发生的点。

**主判决轴**：VOC penult，记 **V**。参照 C5 = 47.23，2φ = 7.76。

| 出口 | 判据 | 含义 |
|---|---|---|
| **U1 局部最优 W 上移** | V ≥ 55.0（= 47.23 + 7.76） | MIL 下 W 越大越好 —— 与 `grid1+mean` **完全反向** → 必须补 W=8.0 |
| **U2 W∈[2,4] 局部平** | \|V − 47.23\| < 7.76 | 与"全局在 W=2.0 已进平台"合起来 → **W=2.0 是全口径工作点**，W 轴关闭 |
| **U3 局部在 W4.0 越界** | V ≤ 39.5 | 与 `grid1+mean` 同向 → MIL 抬高了曲线但保留了越界点 → 与臂 2 的 S2 相互印证 |

**副判据**：
1. **全局五口径 vs `grid1+mean` W4.0**（52.99 / 52.53 / 34.40 / 34.18 / 24.65）——
   `grid1+mean` 在 2.0→4.0 上全局已进平台；MIL 下是否也平（若 MIL 下 W4.0 全局还在涨，
   说明 MIL 把全局的平台点也推高了，那是个独立的新结论）。
2. **Urban i2t vs 18.50 / DOCCI i2t vs 19.26** —— `grid1+mean` 的 W4.0 是长文本 Urban 归零点。
   ⚠️ Urban 无否决权。
3. ADE penult vs 1.78：`grid1+mean` 在这里把区域监督收益 **100% 交回**且 aAcc 净负 ——
   MIL 下是否还这样，是"越界"这个说法能不能保留的关键。

**押注**：**U3**。理由：越界的机制读法是"框级粗粒度压过 patch 级"，MIL 只改**框内**聚合，
不改"框级监督占总损失 80%"这件事。

# 臂 5：C9 —— G + MIL（三损失配方 × MIL，选型收口）

**为什么排最后**：目前的选型表是**硬分裂**的 ——「要长文本 → G@W0.2 不许动 W」、
「要图像塔+分类 → 区域单跑 W2.0」、「要局部分割 → 目前无可推荐配方」。
C5 把局部推到全项目最高且全局零显著代价，所以最后一个问题是：
**MIL 能不能迁移进三损失配方，做出一个吃三族的配方。**

**⚠️ 事前必须声明的功效限制（§6.3 第 5 条：指定仲裁口径前先查参照点间距）**：
G@W0.2 的局部参照点**自身是双峰的**（VOC penult 39.10 / 18.33，散布 20.77）。
→ **「C9 超过 G」这类比较一律不可判，不设为判据。** 局部一侧只与 **C5 的 47.23** 比。

**主判决**：不是单轴，而是"三族是否兼得"的**联合判据**。

| 出口 | 判据 | 含义 |
|---|---|---|
| **V1 三族兼得** | DOCCI i2t ≥ 66.22 **且** t2i ≥ 65.58（都是 G s0 −2φ）**且** VOC penult ≥ 39.5 **且** k-NN bb ≥ 43.93 | 交付级：**一个配方同时守住长文本、拿到 MIL 级局部、图像塔不塌** → 选型表合并 |
| **V2 长文本守住、局部没到 MIL 水平** | 长文本两条满足，VOC penult < 39.5 | **MIL 在三损失配方里不迁移** → 选型表保持分裂，且给出"MIL 需要纯区域臂"这个新限定 |
| **V3 长文本被吃掉** | DOCCI i2t ≤ 66.22 **或** t2i ≤ 65.58 | G+MIL 不是兼得配方 → §5.21.5 的长文本代价在三损失配方上同样成立（跨配方族复现，是个独立收获） |
| **V4 落进坏盆地** | VOC penult < 24.23 **且** 出现 `last < penult` 反序 | 三损失配方的双峰性与 MIL 无关，属该配方本身 → **G 线整体降级为"长文本专用且不稳"** |

⚠️ V1 与 V3 的判据在长文本上互补且穷尽；V2/V4 用局部再分一次 —— 四个出口覆盖全部符号组合。
⚠️ 数据量混淆项仍在：`clip_train_pcmregion.tsv` 198.4 万 vs 纯区域臂 286.9 万（少 31%）
→ **C9 与 C5 的局部差值里混着数据量效应**（§5.15 实测唯一数据减半只值 −3.2~−4.0，
可用来给这一项定上界，但拆不干净）。**这一点必须写进结论段，不许省。**

**押注**：**V2**。理由：MIL 的收益机制是"抗稀释"（§5.21.6），而三损失配方里区域分支
只占 W=0.2（损失占比 18%），抗稀释的收益要先穿过一个很小的权重。

# 通用规程（五臂共用）

1. **判决先行**：拿到数就先报出口代号，再解释。押注写下但不参与判决。
2. **口径读 `params.txt`，不猜目录名**。每臂必查：`region_roi_grid` / `region_roi_agg` /
   `region_weight` / `max_region` / `region_gather` / `region_cc_weight` / `seed` / `epochs`，
   以及 ckpt = 10/10。不过闸就不写结论。
3. **管线漂移校验**：每臂评测段并排重跑一个**已知值**的老 ckpt（用 CTRL W2.0 的
   VOC penult = 24.23），复现不了就先查管线再看新数。
4. **两个都报**：mIoU 与 aAcc（§5.13 教训）；原始与去共同分量（若做 `nbr`）。
5. **`Region_loss` 只用来核对强度对齐，不用来选配方**（§5.21.3：它对局部下游连排序都反）。
6. **ep5 也评 OVSS 四读出**：用来分开"终点抽样"与"结构性差异"（§5.13 / §5.21.2 都靠这个）。
7. **借来的地板只当量级读**。跨配方族借地板在 OVSS 上实测偏 9~32×。
8. **Urban 排除否决权**；DOCCI 是长文本主口径。
9. 每臂判完即写结果页小节 + 更 memory + `commit && push`（开发机随时被回收）。
