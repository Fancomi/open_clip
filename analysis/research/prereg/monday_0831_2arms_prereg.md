# 臂 1：C9F —— 修掉三损失族的 −31% 数据混淆项（Task #30）

**唯一变量**：训练表 `clip_train_pcmregion.tsv`（198.4 万）→ `clip_train_pcmregion_full.tsv`（286.9 万）。
⚠️ **同 Task #21 的 A 轴，带同一个混淆**：固定 10 ep ⇒ 优化步数也 **+44.6%**，
方向与"多数据"相同 → **一切正向幅度都只能读作上界**。
Task #21 的轴分解（B/C 拆窗口与丢行）测到"收益几乎全部来自不丢行"，故本臂按同一读法。

**主判决**：**图像塔一侧**（这是修数据最该动的地方，也是 §5.28.4 留下的空洞）。
记 **P** = k-NN backbone、**Q** = IN-1k top1、**R** = VOC penult mIoU。

| 出口 | 判据 | 含义 |
|---|---|---|
| **X1 混淆项确认，图像塔坑被填** | P ≥ **45.6**（+1.0 ≥ 10× 自己的 0.10 地板，且 ≥ Task #21 增量的 45%）**且** Q ≥ **27.0** | **三损失族全部旧结论的图像塔一列都要按此上修**；§5.28.4 那个"没有已知来源的 −7.9 k-NN 坑"归给数据量；`_full` 表定为三损失族的生产表 |
| **X2 只涨分类不涨骨干** | Q ≥ 27.0 **且** P < 45.6 | §5.28.4 的「W 抬的是对齐不是骨干」升级为**「凡在这一族里动任何东西，IN-1k 与 k-NN 都会脱钩」** → k-NN 坑的来源只剩 PCM 分支本身，且**没有旋钮能填它** |
| **X3 数据量在这一族不值钱** | P < 45.6 **且** Q < 27.0 | 与 Task #21 在 PCM 族的结果**相反** → 「修丢行值 +2.14 IN-1k」是 PCM 单分支族的性质，不跨族；⚠️ 此出口下**必须先排除"落进坏盆地"**（看 R 与形态签名）再写结论 |
| **X4 图像塔涨但局部塌** | （P ≥ 45.6 或 Q ≥ 27.0）**且** R < 45.5 | 数据量与局部是 trade-off，或落进坏盆地 —— 两者**靠形态签名区分**：`last > penult` 成立则是 trade-off，反序则是盆地 |

阈值来处（事前算好，不许事后调）：
- **P ≥ 45.6**：C9 44.58 + 1.0；Task #21 的 k-NN bb 增量是 +2.22 → 门槛只要 45% 即算"填了"。
  1.0 点 = **10× 三损失族实标地板 0.10**，不存在分辨力问题。
- **Q ≥ 27.0**：C9 25.98 + 1.02；Task #21 的 IN-1k 增量 +2.14 → 门槛取 48%。
  1.02 = **1.16× 地板 0.88**（勉强，故 Q 只作联合判据的一半，不单独判）。
- **R ≥ 45.5**：与 §5.26/§5.27 同一条线（C9 s0 − 2×2φ_MIL），**两批共用便于交叉读**。

**副判据**（不单独否决，只改陈述）：
1. **形态签名**（`last > penult`、VOC last 是否在 50 量级）→ 第三次盆地抽样。
   C9 家族目前 s0 好 / s1 坏 → 无论 C9F 落哪边都增加信息。
2. **长文本**：DOCCI 两轴。Task #21 在 PCM 族上测到不丢行对长文本也是正的
   → **事前预测 C9F 的 DOCCI ≥ C9**；若反而降 ≥2× 地板（i2t <66.30 / t2i <65.10），
   说明"多 31% 短 caption 的图"对长文本对齐是稀释，那是新机制。
3. **有效吞吐**：应与 C9 的 942 samples/s 在 ±5% 内（换表不换任何超参）。
   若明显更慢，先查是不是运行时截断的开销（Task #21 在 dual 上测到 320 窗口贵 14~16%，
   但本臂窗口不变，**不该有额外开销**）。
4. **ep9 五项损失 epoch 均值**（按 §5.27 铁律用均值）：`Region_loss` 应与 C9 的 0.9206 同量级；
   差 >5% 先查平凡解释（表里 regions 字段的分布变了）。

**押注（写下但不参与判决）**：**X1**。理由：Task #21 的轴分解显示收益几乎全部来自"不丢行"
且九个口径 95~115% 同向，而三损失族与 PCM 族共用同一个 `caption_dense` 列和同一个丢行规则
→ 没有理由不迁移。⚠️ 反方向顾虑：三损失族多一条区域损失，
§5.15 已测到**区域监督部分替代唯一数据多样性**（H3）→ **数据量在这一族本来就更不值钱**，
这条直接推向 X3，且它是本项目自己测出来的、不是猜的。

# 臂 2：C9Fs1 —— 在生产表上重标三损失族的地板与双峰（Task #31）

**唯一变量**：相对 C9F 只换 `--seed` 0 → 1。
**问的是**：把 −31% 的数据混淆项修掉之后，**局部一侧还双峰吗？**

记 **X** = VOC penult mIoU，参照 C9F 的实测值（**臂 1 落地后才知道，故本臂判据写成相对形式**）。

| 出口 | 判据 | 含义 |
|---|---|---|
| **Z1 双峰消失** | \|X − X_C9F\| ≤ **6.06**（2×2φ_MIL）**且** 两臂形态签名都正常 | **数据量不足是双峰的成因** → §5.27 的 W3 降级为"丢行表上的现象"，C9 配方恢复为可推荐；三损失族地板按本对重标（会小一个量级） |
| **Z2 仍然双峰** | \|X − X_C9F\| > **20**（≈ C9 那对 29.23 的 2/3）**或** 有一臂形态反序 | **双峰与数据量无关** → §5.27 结论全部保留，成因回到「有 PCM 分支 + W 低」这两个拆不开的解释上；选型表长文本那一格必须永久标注"局部不可用" |
| **Z3 中间带** | 6.06 < \|X − X_C9F\| ≤ 20 且形态都正常 | 散布缩小但没消失 → **数据量是双峰的一个成因而非唯一成因**；地板重标为实测值，幅度一律报两 seed 均值 |
| **Z4 两臂都在坏盆地** | 两臂 X 都 < 32.0 或都反序 | 反方向出口：**`_full` 表把好盆地弄丢了** → 与 X1/X3 无关地否掉"换生产表"这个动作本身，必须回退默认值（`visreg.sh` 默认值已保持不动，回退零成本） |

**副判据**：
1. **全局与长文本的 seed 散布**：C9 那对是 k-NN 0.10/0.33、IN-1k 0.88、DOCCI 1.41/1.92
   → 若本对同量级，则「全局与长文本地板可跨族互借」（§5.27）拿到第二次支撑。
2. **ADE penult aAcc**：§5.27 测到它对盆地全盲（0.07×）而 §5.28 测到它对 W 极灵敏（54.8×）
   → **事前预测本对的散布仍 <1×**；若它这次跟着盆地动，那条"盆地盲"的性质就是丢行表专属的。
3. **五项损失 epoch 均值两 seed 差 <1%**（用均值，不用末 batch）。

**押注**：**Z2**。理由：§5.27 已把双峰归因到「有对应损失但强度不足」——
W=0.2 时区域分支虽占约一半损失，但**局部信号本身弱**；多 31% 的数据不改变这个强度。
⚠️ 反方向顾虑：C9 那对的两个终点差 29.23 点而训练侧全盲，**这种大坑常与数据/采样顺序有关**，
多 44.6% 的样本会把 epoch 内的顺序打散得更均匀 —— 这条支持 Z1，但只是机制猜测。
