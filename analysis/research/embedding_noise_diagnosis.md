# CLIP 空间 embedding 噪声消融诊断（2026-08-08）

基于 cc3m gt（E 最优配方，256 context，tsv）的 5+5 组噪声消融实验。

## 一、已完成的 5 组结果（baseline: COCO 24.10 / IN 23.48）

| 组 | 配置 | 角度 mean/std | COCO i2t R@1 | IN-1k top1 | vs baseline |
|---|---|---|---|---|---|
| n_g05 | GaussElem 0.5 | 26.6° / 0.7° | 22.66 | 23.00 | -1.44 / -0.48 |
| n_g325 | GaussElem 3.25 | 72.9° / 1.9° | 3.44 | 5.32 | -20.66 / -18.16 |
| n_uniform | Uniform 45-75° | 59.9° / 8.3° | 14.60 | 17.58 | -9.50 / -5.90 |
| n_mix05 | Gauss 0.5 + 15%@45-75° | 31.8° / - | 21.66 | 22.94 | -2.44 / -0.54 |
| n_mix325 | Gauss 3.25 + 15%@45-75° | 70.9° / 6.1° | 6.94 | 9.62 | -17.16 / -13.86 |

## 二、关键观察：n_mix325(6.94) > n_g325(3.44)

强高斯(3.25)单独严重破坏(3.44)，但**加 15% 角度后提升 +3.5pt**(6.94)。
反向地，温和高斯(0.5)加角度反而略降(22.66→21.66)。

## 三、机制分析

### 1. 高斯 vs 角度的本质区别

- **GaussElemNoise**: `embed += N(0, vec_norm/√D)`，再 normalize。
  vec_norm=3.25 时各维加 σ=0.117 的高斯，**改变向量方向和范数后拉回**，
  各维度尺度信息被抹平。
- **UniformAngleNoise**: 纯旋转（保持范数），只在方向空间扰动，
  **保留各维度的相对尺度信息**。

→ **角度噪声保留更多信息**。这解释了纯角度(60°, 14.60)远好于强高斯(73°, 3.44)。

### 2. 为什么 n_mix325 > n_g325

对比训练 loss 曲线：
- n_g325: Contrastive_loss 9.90→8.44@ep3, Logit Scale 15→30.6（快速膨胀）
- n_mix325: Contrastive_loss 9.89→8.38@ep3, Logit Scale 15→27.1（较慢膨胀）

**Logit Scale 膨胀是"cheat"信号**：模型无法对齐时放大 scale 让 loss 表面降低
（logsigmoid 饱和）。n_mix325 的 scale 膨胀更慢 → **更难 cheat，被迫学习更多
真实结构**。加角度引入了方向多样性（std 1.9°→6.1°），打破"整体旋转 cheat"
的可能。

### 3. 反向：为什么 n_mix05 < n_g05

温和高斯(0.5, 26.6°)已是合理扰动，加 15% 大角度(60°)引入**过度困难样本**，
反而干扰已近收敛的对齐。→ 温和噪声下角度是噪音，强噪声下角度是救兵。

## 四、小角度假设

如果"角度保范数 + 引入方向多样性"是增益来源，那么**小角度(5-30°)纯旋转**
应是最优增强：保留信息 + 适度困难样本 + 不破坏对齐。

正在实验（noise-small，5 组）：
- n_s5_20 / n_s10_30: 纯小角度
- n_g05_a5_20 / n_g05_a10_30: 温和高斯 + 小角度
- n_g05_a10_30r30: 更高混合比

## 五、小角度消融结果（noise-small，2026-08-09 完成）

| 组 | 配置 | COCO | 峰值 | IN | vs baseline |
|---|---|---|---|---|---|
| **n_s5_20** | 纯角度 5-20° | **23.36** | **24.08** | **23.18** | **-0.74 / -0.30** |
| n_s10_30 | 纯角度 10-30° | 22.62 | 23.56 | 23.11 | -1.48 / -0.37 |
| n_g05_a5_20 | Gauss0.5+15%@5-20° | 22.16 | 23.40 | 23.04 | -1.94 / -0.44 |
| n_g05_a10_30 | Gauss0.5+15%@10-30° | 22.10 | 22.80 | 23.00 | -2.00 / -0.48 |
| n_g05_a10_30r30 | Gauss0.5+30%@10-30° | 22.44 | 23.06 | 23.12 | -1.66 / -0.36 |

**结论：小角度是甜点假设完全验证。**
1. n_s5_20（纯小角度 5-20°）是 10 个噪声配置中最优：COCO 23.36 / IN 23.18，
   峰值 COCO 24.08 基本追平 baseline（24.10）
2. 纯角度 > 混合 > 纯高斯：角度保范数保留信息，高斯变范数破坏信息
3. 角度越小越好：5-20° > 10-30°（小扰动 = 困难样本增强，不破坏对齐）
4. IN-1k 全部 23.0% 附近（baseline 23.48），小角度对分类几乎无损

## 六、最终结论

1. **CLIP 对比训练中，高斯噪声（变范数）比角度噪声（保范数）破坏更大**
2. **强噪声下角度混合提供恢复力（std 多样性阻止 scale cheat）**
3. **小角度（5-30°）可能是甜点**——待 noise-small 验证
