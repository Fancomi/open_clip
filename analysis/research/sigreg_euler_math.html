从欧拉公式到 SIGReg

四个问题：欧拉和傅里叶谁是谁的基础？为什么 cos 管形状、sin 管对称？为什么要 mean？哪些是数学，哪些是人为设计？

1欧拉和傅里叶：一个是零件，一个是机器

不等价。欧拉公式是傅里叶变换的基础，反过来不成立。

三个公式串起来看，一眼就明白：

一句话：欧拉说「一个复指数 = 一对三角函数」；傅里叶说「拿这个复指数去和函数做积分，就能看出函数含哪些频率」。 前者是后者的原料。

2为什么要用复数

特征全是实数。复数只是记账工具。

先破一个误解：复数不在你的特征里。投影值 x = Z·w 是实数，backbone 每个输出都是实数。

那复数从哪来？因为要描述频率 t 上的一个振荡，需要两个数：一个记「和 cos 对齐的成分」，一个记「和 sin 对齐的成分」。 这两个数正交、谁也代替不了谁。复数正好是「一对有序实数」的容器：

eitx = cos(tx) + i · sin(tx)
实部装一个分量，虚部装另一个。用一个复数代替两个分开的数，代数上更省事——这就是全部理由。

唯一真正的前提

「能不能用欧拉公式」没有前提，只要看到 e^(i·实数) 就一定能拆。真正的前提在上一步：期望 E[eitx] 得存在。而这条无条件满足：

| eitx | = √( cos² + sin² ) = 1
模长恒等于 1 ⟹ 被积的东西有界 ⟹ 期望对任何分布都收敛。 这就是特征函数比 E[etx]（可能发散）好用的根本原因：它永远存在。

3cos 管形状，sin 管对称

因为 cos 是偶函数、sin 是奇函数。就这一条。

把一个样本 x 和它的镜像 −x 放一起看：

cos(−tx) = cos(tx) 　→ 两边同号，相加　→ 看不出左右，只看出「摊得多宽」= 形状
sin(−tx) = −sin(tx) 　→ 两边反号，抵消　→ 只有左右不平衡才留下 = 对称性

所以对称分布的 sin 项两两抵消、必然为 0；sin 项不为 0 就是偏斜的铁证。而 cos 项对对称分布不抵消，它累起来描述宽窄和尾巴。

实测：四种分布的读数

N=4000 样本实算，按 SIGReg 的定义把两项误差分开统计：

分布（都已标准化）cos 项误差sin 项误差说明
高斯（对照）0.00060.0035都≈0，通过
偏斜0.1731.062sin 抓到不对称
双峰（对称）1.2280.0001cos 抓到形状，sin 完全看不见

双峰那行最能说明问题：它左右对称，所以 sin 项几乎精确为 0（0.0001）——sin 完全看不见它有两个峰； 但 cos 项 1.228，准确报出形状不对。偏斜那行正相反，sin 项 1.062 主导。两项各管一半，缺一不可。

4为什么要 mean

因为特征函数的定义就是期望，而期望在有限样本上就是求平均。

φ(t) = E[ eitx ] 　理论定义，对整个分布
φ̂(t) = (1/N) Σn eitxn 　样本估计 ← 代码里的 .mean(0)
没有 mean，就只是单个样本的一个点，不含任何分布信息。mean 把 N 个样本的振荡加起来平均，得到这批数据在频率 t 上的集体响应。

直观：mean 就是「一堆箭头求和」

把每个样本的 e^(itx) 看成单位圆上一个箭头（长度都是 1，角度是 t·x）。mean 就是把 N 个箭头加起来除以 N。三种情形一目了然：

mean 的附带好处：跨卡精确合并

all-reduce-mean( mean单卡 ) = mean全局 ✓ 精确无损
mean 是线性的，所以跨卡求平均等于全局 batch 的 mean，只需传 17×K 个标量。 VISReg 的 shape 含 sort——「排好序的第 3 名」跨卡求均值毫无意义，只能 all-gather 整个 batch。这是 SIGReg 的一个真实优势。

5loss 怎么组装

要比两个复数（算出来的 φ̂ 和目标 φ），用差的模长平方 = 实部差² + 虚部差²。 高斯的 φ 是纯实数（虚部为 0，因为高斯对称），所以虚部差就是 sin_mean 本身：

| φ̂(t) − φ(t) |² = ( cos_mean − e−t²/2 )² + sin_mean²
左项把 cos 曲线拉向高斯钟形（对齐形状）；右项把 sin 压到 0（强制对称）。 其中 e−t²/2 是标准高斯的特征函数，有闭式解。

然后在 17 个频率上加权求和，对 K 个方向取平均，最后乘全局样本数：

L = N·W · meanK [ Σj wj · ( ( cos_meanj − φj )² + sin_meanj² ) ]
N·W = batch × 卡数。为什么要乘：特征函数是均值量，跟 batch 多大无关；不乘的话大 batch 下正则占比会被稀释。 这正是 VISReg 权重必须重新标定的原因——VISReg 天然与 batch 无关，不乘这个因子，两者裸损失量级差好几个数量级。
x_t = (x @ A).unsqueeze(-1) * t # 投影 × 频率 cos_mean = x_t.cos().mean(0) # 实部　← mean 在这 sin_mean = x_t.sin().mean(0) # 虚部 err = (cos_mean - phi)**2 + sin_mean**2 loss = (err @ weights).mean() * N * world_size

6哪些是数学，哪些是人为设计

你问的核心。答案是分层的：底层全是数学，上层才是设计。

环节归属为什么
eiθ = cos θ + i·sin θ数学恒等式，来自泰勒级数和 i²=−1
傅里叶用复指数当核数学变换的定义，依赖欧拉提供零件
特征函数唯一决定分布数学概率论定理——这是「比 φ 就等于比分布」的合法性来源
特征函数永远存在数学|eitx|=1 有界，期望必收敛
cos 管形状、sin 管对称数学奇偶函数在 ±x 上相加/相消
高斯的 φ = e−t²/2数学可解析积出的闭式解
用 mean 估计期望数学+惯例无偏估计，大数定律保证
取 17 个节点、t 到 3人为设计Epps-Pulley 1983 的工程折中，可改
梯形权重 × 高斯窗人为设计数值积分方案的选择，可换
乘 N·world_size人为设计为「batch 不变性」加的缩放
把统计检验当 loss 用人为设计SIGReg 的真正创新——把假设检验改造成可反传的正则项

底层全是数学：欧拉公式、傅里叶框架、特征函数的唯一性和有界性、cos/sin 的奇偶分工—— 1930 年代概率论就定下的，不是谁「设计」的。

上层才是设计：取几个频率点、怎么加权、要不要乘 batch 因子，以及最关键的「把 Epps-Pulley 检验改造成能反传的 loss」。 SIGReg 的贡献在这一层。

7和 VISReg 的分野

 SIGRegVISReg 的 shape 项

总结：复数、欧拉、cos/sin 这一整套，是「进频域用特征函数比分布」这条路线的必备装备。 VISReg 选择留在空域用最优传输，所以完全不需要它们。 cos 管形状、sin 管对称、mean 做期望估计——这三件事不是设计选择， 而是「决定用特征函数」之后的直接推论。
